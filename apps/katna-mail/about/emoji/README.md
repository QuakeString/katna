# Emoji in About

The emoji in the little play inside "Buy me a coffee"
(`src/window/about/coffee.rs`), 64 px, from
[Noto Emoji](https://github.com/googlefonts/noto-emoji) by Google, under the
Apache License 2.0, as packaged in `emoji-datasource-google` 16.0.0:

| File | Emoji |
| --- | --- |
| `coffee.png` | U+2615 hot beverage |
| `tea.png` | U+1F375 teacup without handle |
| `pizza.png` | U+1F355 slice of pizza |
| `pleading-face.png` | U+1F97A pleading face |
| `crying-face.png` | U+1F622 crying face |
| `droplet.png` | U+1F4A7 droplet |
| `smiling-face.png` | U+1F60A smiling face with smiling eyes |
| `yellow-heart.png` | U+1F49B yellow heart |
| `sparkles.png` | U+2728 sparkles |

They are pictures rather than text so they show in colour on every desktop:
GPUI draws an emoji from the first font that has it, and a black-and-white
font such as DejaVu Sans often comes first.
