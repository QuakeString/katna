# Katna

A fast, modern personal-information-management suite for Linux, written in
Rust: **Katna Mail**, **Katna Calendar** and the **Katna** background
service, with deep KDE Plasma and GNOME integration. An alternative to KDE PIM.

Status: early development (Phase 0).

- [Architecture](docs/ARCHITECTURE.md)
- [Implementation plan](docs/IMPLEMENTATION_PLAN.md)

## Building

```sh
cargo build --workspace
cargo test --workspace
```

Rust: latest stable (installed automatically by rustup from `rust-toolchain.toml`).
